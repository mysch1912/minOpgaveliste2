# Min Opgaveliste

Min Opgaveliste er en simpel mobilapplikation udviklet i React Native med Expo.

Formålet med appen er at give brugeren et simpelt og overskueligt overblik over sine opgaver.

## Funktioner

Appen består af fire forskellige screens:

- Forside
- Opgaver
- Profil
- Om appen

Brugeren kan navigere mellem de forskellige screens ved hjælp af knapper.

På siden "Opgaver" vises en liste med forskellige opgaver.

## Teknologier

Applikationen er udviklet med:

- React Native
- Expo
- React Navigation
- JavaScript

## Struktur

Koden er opdelt i forskellige mapper:

- `screens` indeholder appens forskellige screens.
- `components` indeholder genanvendelige komponenter som knapper og menu.
- `styles` indeholder appens styling.
- `assets` indeholder blandt andet appens baggrundsbillede.

## Start applikationen

For at starte applikationen køres følgende kommando i terminalen:

```bash
npx expo start
